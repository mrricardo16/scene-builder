# CAD-DXF-01：真实 DXF 支持闸门

## 目标

将当前合成样本 DXF 链路从 Partial 推进到由真实匿名样本证据约束的支持结论。

## 前置、输入与契约

输入是合规、匿名的真实 DXF 样本和受控运行环境；复用现有 DXF Adapter、诊断、几何、轮廓、修复、规则和 SceneDraft 契约。不得将样本、绝对路径、图层/Block 原文或客户信息提交至仓库。

## 范围与非目标

覆盖实体范围、Layer/Block/Xref 摘要、单位、Bounds、错误诊断、重复性和取消。非目标是声称任意 DXF 支持、增加 DWG、修改 Domain 依赖或用测试工具替代用户入口。

## 验证与退出

在固定目标 Windows/.NET 环境对匿名真实样本重复运行，保留脱敏工具版本、耗时、指纹和结果摘要；验证可取消与失败诊断。仅在所有接受标准满足后，才可由矩阵将对应 DXF 结论上调。
