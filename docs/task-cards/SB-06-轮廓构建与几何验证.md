# SB-06：二维轮廓构建与几何验证

## 目标

将 SB-05 产生的 `NormalizedCadGeometryDocument` 转换为 parser-independent 的二维曲线段和 `CadContourDocument`，并对源定义的闭合轮廓进行可追溯的有效性判断。

## 输入、契约与产物

- 输入：局部米制 `NormalizedCadGeometryDocument`；不接受未标准化坐标作为替代输入。
- 契约：`CadGeometryTolerance`、`CadCurveSegment2`、`CadLineSegment2`、`CadArcSegment2`、`CadContour`、`CadContourDocument`、`CadContourBuildResult`。
- 产物：闭合 `LWPOLYLINE` 和 Circle 的轮廓，以及没有自动闭合的 `OpenSegments`。
- 证据：Domain 单元测试、Cad 合成 DXF 串联测试、严格 UTF-8 与隐私扫描。

## 进入与退出条件

进入前：SB-05 已给出单位统一、局部原点与有限坐标；输入样本为公开合成数据或私有脱敏验证数据。

退出前：直线、polyline bulge、ARC、Circle 的映射有断言；面积、方向、范围、连续性、零长度、近零面积、非平面和自交均有测试；无效候选保留诊断且不会触发自动修复。

## 非目标

不进行散乱实体拼接、吸附、顶点移动、布尔几何、自交修复、洞关系、规则分类、SceneDraft 生成、Block 展开、DWG 解析、Blender、Tiles 或任何外部进程调用。

## 诊断与门禁

诊断代码为稳定 ASCII：`CONTOUR_ZERO_LENGTH_SEGMENT`、`CONTOUR_SEGMENTS_DISCONNECTED`、`CONTOUR_NOT_CLOSED`、`CONTOUR_AREA_TOO_SMALL`、`CONTOUR_NON_PLANAR`、`CONTOUR_SELF_INTERSECTION`。subject 仅可使用匿名轮廓或源序号；禁止写入绝对路径、真实图层名、客户信息或坐标负载。

候选全部有效或仅有开放段时为 `Succeeded`；存在无效候选时为 `PartiallySucceeded`，仍保留可用候选；输入未标准化等不可用状态才为 `Failed`。
