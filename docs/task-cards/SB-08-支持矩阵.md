# SB-08：支持矩阵闸门

## 目标

以可验证状态对外说明格式和工具支持范围。

## 通过闸门

- 每项能力标明“接口已定义”“未配置”“不支持”或经样本验证的可用状态。
- 不把工具发现、接口定义或空实现误写为转换支持。
- DXF、DWG、Blender 与 Tiles 的状态和验收条件见《CAD 支持矩阵》。

## 当前状态

矩阵已建立；不存在已验证的 DWG 或 3D Tiles 转换支持。
