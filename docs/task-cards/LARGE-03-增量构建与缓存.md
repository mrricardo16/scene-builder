# LARGE-03：增量构建与缓存

## 目标

在计划修订、分区和资产依赖稳定后，定义可验证的增量构建与缓存策略。

## 前置、输入与契约

依赖 LARGE-01、LARGE-02、Frozen Conversion Plan、稳定分区 ID 和受控作业目录。缓存键必须包含计划修订、输入/资产指纹、工具版本、分区策略、优化配置和输出格式；缓存命中与绕过要可审计。

## 范围与非目标

只缓存可证明不受变更影响的中间或最终产物。不得用未验证缓存替代 Build、跨项目泄露资产、覆盖旧 Job、静默使用过期产物或引入数据库/云同步。

## 验证与退出

验证命中、失效、工具版本变化、计划/资产变化、取消、损坏缓存、跨项目隔离和结果哈希一致性。退出时缓存只能标为已验证策略，不代表大厂区整体 Production Ready。
