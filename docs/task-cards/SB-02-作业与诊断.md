# SB-02：作业与诊断闸门

## 目标

保证每次运行可追溯且输出仅位于调用方给定的作业目录。

## 通过闸门

- `JobLayout` 生成 `input`、`intermediate`、`output`、`reports` 子目录布局。
- 非法作业标识不能逃逸到作业目录外。
- 报告记录状态、诊断和产物；没有产物时不能报告成功。

## 当前状态

布局与报告契约已有测试。通用运行限制见《运行规则》。
