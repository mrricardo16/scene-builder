# SB-07：几何容差、散线连接与受控修复

## 目标

在 `CadContourDocument.OpenSegments` 上识别受限修复候选，生成可审计、稳定排序的 `CadGeometryRepairPlan`，并只在策略允许时应用安全动作，最后复用 SB-06 验证修复结果。

## 已支持

- 同层端点邻近分析、受控直线端点吸附和小缺口桥接；
- 同向/反向完全重复直线识别与稳定保留；
- 无分支连续共线直线合并；
- 简单段链和闭环发现；
- 冲突计划阻止自动应用；
- 动作、计划和生成段的稳定匿名 ID；
- 原始文档不变、修复动作审计、修复后复用 `CadContourValidator`。

## 默认安全边界

所有距离以局部米制 XY 计算，并受 Z 差阈值限制。默认禁止跨图层；圆弧可参加桥接端点，但不会被吸附重定义；自动应用仅限 `Deterministic` 和 `High`。分析、计划、应用完全分离。

## 非目标

不进行复杂图网络求解、默认跨图层修复、大缺口自动补线、自交自动修复、Polygon 布尔运算、洞/外环关系、规则或厂房语义识别、SceneDraft、Blender、Tiles、DWG、ezdxf、Xref 或 JobReport v0 修改。

## 门禁

修复计划必须确定性排序，冲突为 `HasConflicts`，不会静默任选动作。每个自动应用后产生独立结果，并由 SB-06 验证连续性、闭合、零长度、面积、非平面和自交；失败或跳过动作保留在审计结果中。
