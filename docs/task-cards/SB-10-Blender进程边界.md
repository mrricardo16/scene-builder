# SB-10：Blender 进程边界闸门

## 目标

仅在基础几何、分区和独立 POC 门禁通过后，定义受控 Blender 进程边界；本卡不授权生成 GLB。

## 通过闸门

- `IBlenderProcessRunner` 使用带取消、超时和残留进程处理的受控执行接口。
- 缺失工具、超时、取消和异常输出均写入脱敏进程报告。
- 在 POC 结论前，产品路径不启动 Blender，也不生成 GLB。
