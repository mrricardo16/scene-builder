# SB-09：性能基线闸门

## 目标

在真实实现出现后，建立可复现且不误导的性能基线。

## 通过闸门

- 固定样本、环境、命令和测量口径。
- 同时记录时延、资源、产物和正确性检查。
- 转换成功性能只能来自已配置、已验证的真实转换路径。

## 当前状态

当前没有真实大型厂区性能或生产容量结论。现有组件和单层 Tileset 验证不替代可重复样本基线；记录模板、目标/实际状态和禁止项见《性能基线》与 LARGE-00。
