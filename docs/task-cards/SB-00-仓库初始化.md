# SB-00：仓库初始化

## 目标

建立 IDTS Scene Builder 的 .NET 8 解决方案骨架、仓库规则和首版项目文档，为后续领域契约与命令行能力提供稳定起点。

## 交付范围

- `SceneBuilder.sln`，包含 8 个源项目和 2 个测试项目。
- UTF-8 编码规则、版本控制规则、执行规则和输出目录规则。
- 项目章程与本任务卡。
- 空基线可成功执行 `dotnet build SceneBuilder.sln` 与 `dotnet test SceneBuilder.sln`。

## 验收标准

1. 解决方案目标框架为 .NET 8。
2. `src/` 下恰有 8 个源项目，`tests/` 下恰有 2 个测试项目。
3. 根目录规则明确要求文本使用 UTF-8，并保护中文内容不被错误转码。
4. 文档说明 DXF 是首条验收路径；DWG 与 3D Tiles 仍是未实现的边界，不能被误报为已支持。
5. 输出文件必须局限在调用方显式指定的作业目录，构建与测试临时产物不提交。
6. 构建和测试命令成功退出。

## 非目标

本卡不创建领域模型、CAD 解析、外部工具探测、DWG 转换或 3D Tiles 转换实现。这些能力由后续任务分别交付并测试。
