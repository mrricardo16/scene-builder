# SB-06：分区规则闸门

## 目标

在不泄漏具体转换器的前提下，将场景分区作为流水线策略。

## 通过闸门

- 输入只使用 `SceneDraft` 的稳定节点与范围数据。
- 分区策略不修改领域契约，也不在领域层引用 Tiles 类型。
- 每个分区的来源、范围和诊断可追溯。

## 当前状态

规则与边界已文档化，尚无分区算法实现。
