# 性能基线

当前代码已包含受限 DXF 分析、受控 Blender GLB、Scene Package 与本地 Cartesian 3D Tiles 1.1 的验证，但尚无可宣称的真实大型厂区性能或生产容量基线。SB-12A 的单层 Root + Leaves 测试不证明 HLOD、Viewer 性能、GPU 占用、内存上限或大场景可用性。

LARGE-00 将在 Small、Medium、Large 与 Stress/Boundary 脱敏样本上建立可重复基线。每次记录必须包含输入规模、CAD 实体/Layer/Block 摘要、分区数、Global 分区、单 Tile GLB 大小、总包大小、Tile 数量、阶段耗时、峰值内存、输出哈希、工具版本、失败/取消和 Viewer 结果。

验收记录必须同时写明 Target、Actual 与状态：Validated、Target 或 Unverified。无真实样本、无固定环境、无重复运行或无 Viewer 验收的数据不得表述为性能结论。详见 [大厂区 3D Tiles 产品规格与验收基线](大厂区3DTiles产品规格与验收基线.md)。
