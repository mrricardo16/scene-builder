# 性能基线

当前阶段没有 DXF 解析、Blender 处理或 Tiles 转换实现，因此不存在可宣称的格式转换性能数据。性能基线必须在可重复的真实样本、固定运行环境和已验证实现上建立。

后续基线至少记录：

| 指标 | 记录方式 |
| --- | --- |
| 样本 | 文件格式、大小、图层数、实体数和范围；必要时脱敏。 |
| 环境 | .NET 版本、操作系统、CPU、内存和外部工具版本。 |
| 时延 | 检查、场景草稿生成、分区和转换分别记录墙钟时间。 |
| 资源 | 峰值工作集、磁盘产物大小和临时目录大小。 |
| 正确性 | 诊断、产物清单、坐标/单位抽样和可重跑结果。 |

不得用“未配置”或失败路径的耗时作为转换成功性能结论。
