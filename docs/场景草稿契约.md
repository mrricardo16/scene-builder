# SceneDraft 契约

## CAD 轮廓前置契约

`CadContourDocument` 是 SceneDraft 之前的几何中间结果，不是 SceneDraft 的 JSON 字段，也不改变当前 `SceneDraft` wire shape。它只描述局部米制 XY 曲线、源定义闭合候选及诊断；不携带图纸路径、真实图层/Block 名称、客户信息或设备编码。后续 SceneDraft 适配器必须显式决定如何消费 `Valid`、`Invalid` 和 `OpenSegments`，SB-06 不自动生成任何 `SceneNode`。

SB-07 可从 `OpenSegments` 派生独立的 `CadGeometryRepairResult`，其中保留原始文档、修复计划、已应用/跳过动作和重新验证后的独立文档。该内部结果同样不是 SceneDraft 或 JobReport 字段；它不授权后续适配器把“可修复”解释为厂房语义或任意 CAD 已清洗。

`SceneBuilder.Domain.SceneDraft` 是 CAD 检查结果进入后续流水线前的稳定场景草稿。

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `Id` | 草稿标识 | 由调用方或应用层确定；不得隐式映射为文件系统路径。 |
| `SourceDocument` | 来源文档摘要 | 使用 `CadDocumentModel`，包含来源路径、格式、单位、显式范围状态、图层、`Blocks`、`EntityTypes` 和诊断。 |
| `SemanticObjects` | 内部厂房语义对象 | 由可信分类和实际来源几何构造，稳定按 `Id` 排序；包含 Wall、Floor、Column、Road、StaticFacility 与 DynamicEquipment。 |
| `Nodes` | 场景节点 | 每个节点有稳定 `Id`、脱敏合成名称、空间范围、语义对象和来源 Subject 追溯，以及明确内容类型。 |
| `Diagnostics` | 草稿级诊断 | 记录可追溯的告警或错误，不以伪造成功掩盖外部工具缺失。 |

`CadBounds` 的范围状态必须连同坐标一起解释：`NotEvaluated` 表示未能完整安全地获得范围，`Empty` 表示已确认输入集合为空，`Computed` 才表示六个坐标均为有效范围。任何范围异常不得以部分对象合成 `Computed`。

`SourceDocument.Blocks` 是普通 Block 定义的摘要：名称、直接子实体数量和 Block 本地范围；它不表示模型空间 `INSERT` 实例，不递归展开嵌套 Block，不包含原始实体负载。`EntityTypes` 只统计模型空间直接实体，类型名为规范化大写 DXF 名称（例如 `LINE`、`LWPOLYLINE`、`INSERT`），不依赖解析器 CLR 类型。

集合字段默认为空集合，不能为 `null`。领域层不保存 ACadSharp、Blender、具体 Tiles 转换器或当前 IDTS 清单类型。`CadDocumentModel` 是内部领域摘要，不能直接作为公开 `JobReport` 或其他外部报告序列化；既有 `JobReport` v0 JSON 属性保持为 `jobId`、`createdAt`、`status`、`diagnostics`、`artifacts`。

已补足的契约缺口是 Block 定义摘要、模型空间实体类型摘要、范围状态歧义，以及模型空间直接 `LINE`、`LWPOLYLINE`、`ARC`、`CIRCLE`、`INSERT` 的基础几何与局部米制坐标标准化。SB-08 在内部完成项目级确定性分类；SB-09 已将可信 Contour、OpenSegment 和 Insert 转换为稳定的厂房语义对象、SceneNode 和 SceneDraft。节点内容明确为程序化静态几何、静态资产引用或动态资产引用，且 Insert 保留标准化 Transform。

这表示系统已经能够将可信二维 CAD 分类结果转换为可供三维建模阶段消费的内部 SceneDraft。SB-10 的内部 Blender Adapter 可消费该草稿，并生成最小单场景 GLB：ClosedProfile Wall 与 Column 按显式高度拉伸，Floor 和 Area Road 生成平面。它不改变 SceneDraft，也不把 Blender、Manifest 或 GLB 类型加入 Domain。

SB-11A 已为静态设施和动态设备接入显式项目级 GLB 映射；SB-11B 已可将一个不变的 SceneDraft 按策略派生为内部的、只含唯一归属对象的分区草稿，并顺序生成多个 GLB 场景包。分区草稿的 Id 仅供内部跟踪，不能用作路径或公开外部契约；SceneDraft 本身不增加分区字段，也不被原地修改。

仍未实现 Wall Baseline 墙厚、Road Centerline Buffer、门窗、屋顶、复杂材质/纹理、动画、LOD、3D Tiles、DWG、ezdxf、Xref 内容加载和代理对象转换。
