# SceneDraft 契约

`SceneBuilder.Domain.SceneDraft` 是 CAD 检查结果进入后续流水线前的稳定场景草稿。

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `Id` | 草稿标识 | 由调用方或应用层确定；不得隐式映射为文件系统路径。 |
| `SourceDocument` | 来源文档摘要 | 使用 `CadDocumentModel`，包含来源路径、格式、单位、范围、图层和诊断。 |
| `Nodes` | 场景节点 | 每个节点有稳定 `Id`、名称、空间范围和来源图层。 |
| `Diagnostics` | 草稿级诊断 | 记录可追溯的告警或错误，不以伪造成功掩盖外部工具缺失。 |

集合字段默认为空集合，不能为 `null`。领域层不保存 ACadSharp、Blender、具体 Tiles 转换器或当前 IDTS 清单类型。
