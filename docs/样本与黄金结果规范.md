# 样本与黄金结果规范

## 分类与目录

公开仓库仅允许合成样本规范和匿名元数据。真实厂房图纸、截图、客户名称、设备编码、坐标、内部路径及任何可回推现场的信息必须保留在授权的私有存储。

| 类别 | 位置 | 可提交内容 | 用途 |
| --- | --- | --- | --- |
| 合成样本 | `tests/fixtures/synthetic/` | 最小 DXF、说明和预期断言 | 单元、Golden、回归 |
| 匿名真实样本 | 私有存储 | 样本 ID、哈希、脱敏后的统计信息 | 兼容性 POC |
| 黄金结果 | `tests/golden/` 或私有存储 | JSON 摘要、断言值、无敏感名称的诊断 | 比对和回归 |

当前公开合成样本位于 `tests/fixtures/synthetic/`：空文档、最小线段、闭合 `LWPOLYLINE`、无单位线段和未映射 `CIRCLE`。它们只使用中性图层名与合成坐标；真实样本仍不得提交。

## 接入和脱敏

1. 为每个样本分配不可逆的 `sampleId`，如 `synthetic-wall-001` 或 `private-anon-001`，不得使用客户、厂区或设备名称。
2. 在私有登记中记录格式、字节数、SHA-256、图层数、实体数、单位和范围；公开记录不得包含原始文件名、绝对路径或精确现场坐标。
3. 真实样本必须先移除标题块文字、外部参照路径、图块属性、用户数据和可识别图层名；无法可靠脱敏的样本不得复制到公开仓库。
4. 每个 Golden 结果只断言稳定且非敏感的数量、类别、单位、归一化范围、诊断代码和节点键，不断言客户命名或原始文本。

## 黄金断言

首个 DXF POC 至少覆盖：空文件、最小有效线段、闭合轮廓、未知单位、未识别实体和损坏输入。每个样本要记录预期退出码、图层数、实体数、诊断代码集合和 SceneDraft 的关键字段。

当前 pre-POC 的 v0 CLI 尚未实现 `inspect`：调用它会因未知命令返回 2，不能产生 DXF Golden 结果。目标 v1 `inspect` 实现但 DXF 解析器仍未配置时，预期为退出码 3、`DXF_PARSER_NOT_CONFIGURED`、空 `artifacts`，且不创建建模产物。下面的成功示例只在 SB-03 通过 DXF POC、解析器已接受且 Golden 测试建立后才有效。

## SB-03 通过后的成功 Golden 示例

```json
{
  "sampleId": "synthetic-wall-001",
  "visibility": "public-synthetic",
  "format": "DXF",
  "expected": {
    "exitCode": 0,
    "layerCount": 2,
    "entityCount": 3,
    "diagnosticCodes": [],
    "sceneDraftNodeCount": 1
  }
}
```

私有样本的复现证据必须记录命令、工具版本、哈希与结果摘要；其原文件不作为本仓库提交物。
