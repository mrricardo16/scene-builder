# Scene Builder 产品目标与能力状态

## 产品目标

Scene Builder 是一款以 Avalonia 为主要操作端的 Windows 本地场景构建工具。用户导入 DWG 或 DXF 后，系统先完成结构分析和初步识别；用户在可视化工作台中调整受控参数并确认计划，随后生成可验证的单体 GLB、分区 Scene Package 和可选的本地 Cartesian 3D Tiles 1.1。

目标流程为：导入 → 受控作业目录 → 输入适配与分析 → 可编辑转换计划 → 确认并冻结计划版本 → SceneDraft → 单体 GLB → 可选 Scene Package → 可选 3D Tiles 1.1 → 验证、预览、历史与重新生成。

这是一条产品目标路线，不等同于当前已经提供的用户入口。当前仓库没有 Avalonia 项目、统一转换服务或完整转换 CLI。

## 状态词

- **Implemented**：代码已实现，但尚未达到独立验收或产品入口条件。
- **Validated**：有对应测试或受控验证证据，仍受其明确边界限制。
- **Partial**：只覆盖明确的子集，不能外推为通用支持。
- **Planned**：已定义目标和约束，尚未实现。
- **Unsupported**：当前不能作为可用能力启动。

## 输入能力

| 能力 | 状态 | 当前事实与边界 |
| --- | --- | --- |
| DXF 合成样本链路 | Partial | 已有结构摘要、几何提取、轮廓、受控修复、规则分类和 SceneDraft 构建代码；公开合成样本覆盖不代表任意 DXF 可生产使用。真实复杂 DXF 仍须通过 CAD 支持闸门。 |
| DWG 直接读取 | Unsupported | ACadSharp 对匿名真实 DWG 的受控直接读取曾超时，不能声称正式支持。 |
| DWG → DXF 受控转换 | Validated | 已有可行性 POC；转换器许可、安装与版本、取消、超时、Xref、代理对象和真实样本回归尚未完成，不能作为产品入口。 |
| 转换后真实 DXF 的 ezdxf POC | Validated | 有私有 POC 正向证据；未接入 .NET 产品代码，也不能替代 DXF 支持闸门。 |

## 转换能力

| 能力 | 状态 | 当前事实与边界 |
| --- | --- | --- |
| 结构摘要 | Implemented | `IDxfInspector` 与当前 Domain 模型提供受限摘要。 |
| 几何提取 | Implemented | 已提取受支持 DXF 实体的标准化几何；实体覆盖受限。 |
| 轮廓构建 | Implemented | 以现有几何契约为输入，不等同于完整 CAD 几何支持。 |
| 受控修复 | Implemented | 仅执行显式策略，不修改原始 CAD。 |
| 规则分类 | Implemented | 复用 `CadRuleEngine` 和严格 JSON 规则契约。 |
| SceneDraft | Implemented | 由已得到的分类、轮廓和几何构建，不会重新解析或猜测规则。 |
| 程序化单体 GLB | Validated | 受控 Blender 进程、取消/超时和 GLB 校验已实现；支持范围以现有 Blender 映射为准。 |
| 显式 GLB 资产实例化 | Validated | 已有显式 AssetId、确定性 Binding、Windows 安全读取和匿名暂存边界。 |
| 多分区 Scene Package | Validated | 已有确定性分区、staging、索引与验证；尚无统一产品入口。 |
| 本地 Cartesian 3D Tiles 1.1 | Validated | 已从已验证 Scene Package 生成 `tileset.json`；不含地理配准、Cesium/IDTS 接入或内嵌预览。 |

## 产品能力

| 产品能力 | 状态 | 说明 |
| --- | --- | --- |
| 完整 `convert` CLI | Planned | 当前 CLI 仅实现 `doctor`。 |
| 统一 `ISceneConversionService` | Planned | 代码库中不存在该服务。 |
| Analyze / Edit Plan / Build | Planned | 尚无统一入口、计划版本或冻结快照。 |
| Avalonia 项目 | Planned | 目前没有 Desktop 项目或 UI。 |
| 导入后的参数工作台 | Planned | 不能以测试工具或 SmokeTest 冒充用户入口。 |
| 二维 CAD 预览 | Planned | 需先完成独立技术验证。 |
| 内嵌 GLB 预览 | Planned | 需先完成 Viewer POC。 |
| 内嵌 3D Tiles 预览 | Planned | 需先完成独立 Viewer POC。 |
| 项目、计划和作业历史 | Planned | 当前没有本地项目存储。 |
| Windows 发布包 | Planned | 尚无 Avalonia 应用可发布。 |
| IDTS Web/API 接入 | Planned | 不属于当前仓库的已实现产品能力。 |

## 对外表述规则

不得把自动化测试、SmokeTest、私有 POC、`doctor` 或底层生成器表述为可供用户执行的完整产品工作流。DWG 在通过支持闸门前始终是 Unsupported；3D Tiles 是已验证的底层输出，不代表已有 Desktop、Cesium 或 IDTS 预览能力。
