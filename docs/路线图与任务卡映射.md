# 路线图与任务卡映射

本映射以 [产品目标与能力状态](产品目标与能力状态.md) 和 [Avalonia Desktop 路线图](scene-builder-avalonia-desktop-roadmap.md) 为唯一产品路线来源。历史 SB-00 至 SB-12A 说明底层能力演进；它们不是当前 Desktop 产品路线，也不得与下列任务卡并列造成冲突。

| 阶段 | 任务卡 | 产物 | 明确非目标 |
| --- | --- | --- | --- |
| 统一入口 | CORE-01 | Analyze / Validate Plan / Build 服务和完整 CLI | Desktop 直连 CAD/Blender/Tiles。 |
| CAD 分析 | CORE-02 | `CadImportAnalysisResult` | 启动 Blender。 |
| 计划 | CORE-03 | 可编辑 Draft、校验结果、Frozen Plan | 修改原始 CAD 或让 Build 读 ViewModel。 |
| 构建 | CORE-04 | GLB、Scene Package、3D Tiles 输出协调 | 重新猜测 UI 参数。 |
| DXF 闸门 | CAD-DXF-01 | 真实 DXF 支持证据 | 以 SmokeTest 冒充通用支持。 |
| DWG 闸门 | CAD-DWG-01 | DWG Adapter 与支持证据 | 在闸门前声称 DWG 已支持。 |
| 桌面验证 | DESKTOP-00 | 2D CAD、GLB、3D Tiles Viewer POC 结论 | 直接交付未验证预览。 |
| 桌面产品 | DESKTOP-01 至 DESKTOP-09 | 宿主、导入、调整、输出、历史、预览、发布 | 改写 Domain 或绕过 Application。 |
| 集成 | INTEGRATION-01 | 可选 IDTS API/Web 适配评估 | 在核心工作流稳定前提前接入。 |

每张任务卡都必须写明目标、前置条件、输入、稳定契约、实现范围、非目标、验证、退出条件与能力状态变化条件。任务卡未完成时，能力状态不得上调。

## 已实现基线的正确引用

当前代码已提供受限 DXF 分析、SceneDraft、受控 Blender GLB、显式资产映射、Scene Package 和本地 Cartesian 3D Tiles 1.1。它们由后续 CORE 任务统一协调；现有 `doctor`、测试和 SmokeTest 不是完整 `convert` CLI、Avalonia 页面或用户产品入口。
