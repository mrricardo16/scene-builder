# 运行规则

1. 调用方必须提供作业输出根目录；运行时产物只能落在该作业目录的 `input`、`intermediate`、`output` 或 `reports` 下。
2. 不得把运行时产物写入仓库根目录、`src/` 或 `tests/`。
3. 外部工具调用必须通过显式请求/结果契约，并接收 `CancellationToken`；未经实现和验证不得启动进程。
4. 诊断必须表达实际状态。工具未配置时报告未配置，DWG 未支持时报告未支持，不得返回伪造的成功产物。
5. 文本文件使用 UTF-8；修改中文文本前必须保留其可读性。
6. DXF 是当前首条验收路径；DWG 和 3D Tiles 需要单独验证后才能宣称支持。
