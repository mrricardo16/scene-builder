# 运行规则

1. 目标 v1 作业命令 `inspect`、`build`、`tiles`、`run` 必须由调用方提供作业输出根目录；其运行时产物只能落在 v1 作业布局 `workspace/jobs/{jobId}/input|normalized|intermediate|chunks|tiles|dynamic|reports|logs` 下。该布局尚未实现，不能误述为当前 CLI 行为。
2. 当前 v0 `doctor` 是例外：`--output` 可选；指定时只直接在调用方提供的目录写入 `doctor-report.json`，未指定时不写文件。`doctor` 不使用 v1 作业布局。
3. 不得把 v1 作业产物写入仓库根目录、`src/` 或 `tests/`。发布前必须审查并脱敏 `doctor-report.json`，因为其中可能含有调用方显式配置的本地工具路径。
4. 外部工具调用必须通过显式请求/结果契约，并接收 `CancellationToken`；未经实现和验证不得启动进程。
5. 诊断必须表达实际状态。工具未配置时报告未配置，DWG 未支持时报告未支持，不得返回伪造的成功产物。
6. 文本文件使用 UTF-8；修改中文文本前必须保留其可读性。
7. DXF 是当前首条验收路径；DWG 和 3D Tiles 需要单独验证后才能宣称支持。
